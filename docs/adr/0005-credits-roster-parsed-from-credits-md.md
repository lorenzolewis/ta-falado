# The About page's roster is parsed from a convention in CREDITS.md

The About page shows the team as a roster: each role, each person's name with a line under it, and their bio. `CREDITS.md` must stay the single source for the credits, and it's also what people read on GitHub. So rather than a data file that both `CREDITS.md` and the page draw from, `CREDITS.md` follows a convention the page parses (`src/lib/credits.ts`): under "The team", each `###` heading is a role, and each person is a list item, `**Name**: line`, with a `###` bio of the same name under "Bios". A data file would have to generate `CREDITS.md`, or be checked against it, and the Markdown would no longer be the thing you edit. The cost is a parser that reads the compiled HTML. It throws on anything that breaks the convention (a person with no bio, a bio with no person, an item without `**Name**: line`), so a slip fails the build instead of dropping someone from the page.

The license and "This site's code" sections are the exception: the page writes them out as prose, while `CREDITS.md` keeps the same facts as a TASL list. A change to the attribution has to be made in both.
